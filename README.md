# AEL scenario codebook (Round 1)

Text dilemma scenarios for the Automotive Ethics Lab, labelled with Codebook v4 (a utilitarian label U and a Kantian label K).
Each situation is written once, expanded into scenes at three levels (high, mid, low), and each scene into an anchor plus "twins" that change one variable at a time.

Everything lives in [`ael_round1_kit/`](ael_round1_kit/). Start with its [README](ael_round1_kit/README.md) for the build steps, and its [CHANGELOG](ael_round1_kit/CHANGELOG.md) for who added what.

Every push runs the build and checks in GitHub Actions (`.github/workflows/build.yml`).
